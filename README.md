# غزاوي ستور — AL-GHAZAWE STORE

متجر لبيع يوزرات إنستقرام وسناب شات وتيك توك، حسابات السوشيال ميديا، باقات سوا وتطبيقات بلس — بواجهة عربية (RTL) مبنية على **Next.js 16 + TypeScript + Tailwind CSS v4 + Supabase**، بهوية بصرية مأخوذة من دليل العلامة (أخضر نيون على أسود زمردي).

> We build your digital presence and turn your ideas into success.

---

## المزايا

- **٧ أقسام و١٥ خدمة**:
  - يوزرات إنستقرام (مميزة، رباعية، شبه ثلاثية، مكررة، شبه أرقام، أحرف)
  - خدمات إنستقرام (نقل يوزرات، زيادة متابعين)
  - يوزرات سناب شات • يوزرات تيك توك
  - حسابات سوشيال ميديا (إنستقرام، تيك توك، سناب شات)
  - باقات سوا (SAWA) • تطبيقات بلس المعدّلة
- **بحث وفلترة وترتيب** لحظي على كل الخدمات.
- **سلة طلبات** محفوظة في `localStorage` مع درج جانبي وخطوة إتمام طلب.
- **زر واتساب** عائم + في الهيدر + على كل خدمة. عند إتمام الطلب تُبنى رسالة واتساب جاهزة بكل التفاصيل ورقم طلب فريد.
- **Supabase** لقراءة الكتالوج وتخزين الطلبات، مع رجوع تلقائي للكتالوج المدمج إذا لم تُضبط المفاتيح.
- **SEO**: `sitemap.xml`، `robots.txt`، Open Graph، وتوليد ثابت (SSG) لكل صفحات الخدمات والأقسام.
- **إتاحة**: دعم `prefers-reduced-motion`، تركيز واضح بلوحة المفاتيح، رابط تخطي للمحتوى، وعمل كامل بدون جافاسكربت.

## ربط Supabase

1. أنشئ مشروعاً على [supabase.com](https://supabase.com).
2. في **SQL Editor** نفّذ `supabase/schema.sql` ثم `supabase/seed.sql`.
3. من **Project Settings → API** انسخ المفاتيح إلى `.env.local`:

```env
NEXT_PUBLIC_SUPABASE_URL=https://YOUR-PROJECT.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=...
SUPABASE_SERVICE_ROLE_KEY=...   # اختياري، يُستخدم في /api/orders فقط
```

بدون هذه المفاتيح يعمل الموقع كاملاً على الكتالوج المدمج في `src/lib/catalog.ts`، وتُسجَّل الطلبات في اللوق بدل قاعدة البيانات — ورسالة الواتساب تصل في الحالتين.

### الجداول

| الجدول | الوصف | القراءة العامة |
| --- | --- | --- |
| `categories` | أقسام المتجر | ✅ للأقسام المفعّلة |
| `services` | الخدمات وأسعارها ومزاياها | ✅ للخدمات المفعّلة |
| `testimonials` | آراء العملاء | ✅ للمفعّلة |
| `orders` | الطلبات الواردة | ❌ إضافة فقط — القراءة بمفتاح `service_role` |

سياسات RLS مفعّلة على الجداول الأربعة.

### تعديل الخدمات والأسعار

عدّل `src/lib/catalog.ts` ثم:

```bash
npm run seed:generate   # يعيد توليد supabase/seed.sql
```

ونفّذ الملف الناتج في Supabase. كل عمليات الإدخال `upsert` فآمن إعادة تشغيلها، وبهذا لا تفترق البيانات المدمجة عن قاعدة البيانات.

بعد ربط Supabase يمكن التعديل مباشرة من لوحة Supabase — الموقع يقرأ منها أولاً ويعيد التحقق كل ٥ دقائق (`revalidate = 300`).
