# ملف اللوقو

ملف الشعار الحالي هو `logo.png` (PNG بخلفية شفافة)، وهو المستخدم فعلياً في الموقع.

لو بدك تستبدله بملف تاني، اتبع الخطوات:

## الخطوات

**١.** انسخ ملف اللوقو هنا، مثلاً:

```
public/brand/logo.png
```

يُقبل `.png` أو `.svg` أو `.webp`. الأفضل PNG بخلفية شفافة بعرض ٦٠٠ بكسل أو أكثر — أو SVG (يبقى حاداً بأي مقاس).

**٢.** افتح `src/config/site.ts` وعدّل:

```ts
export const brandMark = {
  src: "/brand/logo.png",   // ← بدّل null بمسار ملفك
} as const;
```

خلص. اللوقو بيظهر تلقائياً في الهيدر، الهيرو، صفحة من نحن، بانر التواصل، وصفحة الخطأ.

## مهم: الخلفية لازم تكون شفافة

الملف لازم يكون **SVG** أو **PNG بقناة شفافية**. إذا كانت الخلفية سوداء أو بيضاء صلبة، رح تظهر كمربع فوق خلفية الموقع الداكنة.

## ملاحظات

- إذا كان المسار غلط أو الملف ناقص، الموقع يرجع تلقائياً للشعار المتجه المدمج — ما بينكسر.
- النسخ أحادية اللون (أبيض / أخضر) بتستخدم الشعار المتجه دائماً، لأن الصورة النقطية ما بتنعاد تلوينها.
- **أيقونة المتصفح** منفصلة: `src/app/icon.png` (٥١٢×٥١٢). و`src/app/opengraph-image.png` هي صورة معاينة الرابط عند المشاركة. استبدلهما بنفس الاسم لو غيّرت الشعار.
